**useState理解**
- 状态更新后，React会重新调用组件的函数体（即重新执行组件函数），然后计算新的return(<></>)部分。
- React 根据新的 JSX 输出和旧的虚拟 DOM 进行 diffing（差异比较），最终仅更新实际需要变动的部分
（即真实 DOM 层面只更新发生变化的内容，而不是整个页面重新渲染）
- 如果父组件状态更新并重新渲染，那么所有子组件也会重新渲染（无论子组件是否依赖该状态），
除非子组件通过 React.memo 或 useMemo 进行了优化
- 深入：视图刷新和性能优化
1. 使用 React.memo 包裹子组件，可以避免子组件在父组件状态变化时不必要的渲染
2. 对于回调函数或复杂计算结果，可以使用 useCallback 和 useMemo 缓存，避免重复计算或不必要的渲染。
3. 将无关的状态拆分成多个 useState，可以减少状态更新时的渲染范围

### React 组件重新渲染的触发条件
- props 或 state 变化时；
- 父组件重新渲染，则子组件跟着~；
- Context变化时，使用该Context的组件重新渲染
- 当 key 发生变化时，React 会卸载旧组件并挂载新组件，从而触发重新渲染
- Redux等全局状态变化

### 避免组件重新渲染造成变量值还原的方案
1. 短期存储、跨渲染周期：使用 useRef。
2. 长期存储、刷新页面后恢复：使用 localStorage 或 sessionStorage。
3. 组件内管理复杂逻辑：使用 useReducer。
4. 多组件间共享状态：使用 Context。
5. 全局持久化和复用逻辑：使用自定义 Hook 或 URL 参数。
